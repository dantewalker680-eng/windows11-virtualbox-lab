# Windows 11 VirtualBox Deployment Lab

## Project Overview

This project demonstrates the installation and configuration of Microsoft Windows 11 in Oracle VirtualBox. The objective was to gain hands-on experience with virtualization, operating system deployment, storage management, networking, and system verification.

## Tools Used

* Oracle VirtualBox
* Windows 11 ISO
* Windows 11 Host Computer

## Skills Demonstrated

* Virtual Machine Creation
* Operating System Installation
* Virtual Hardware Configuration
* Network Configuration Verification
* Storage Management
* System Documentation
* Basic Troubleshooting

## Installation Process

### Step 1: Create Virtual Machine

Configured a Windows 11 virtual machine in Oracle VirtualBox with appropriate CPU, memory, and storage allocations.

### Step 2: Install Windows 11

Installed Windows 11 using a Microsoft ISO image and completed the initial setup process.

### Step 3: Install Guest Additions

Installed Oracle VirtualBox Guest Additions to improve display support and integration features.

### Step 4: Verify System Configuration

Reviewed device specifications, system information, disk configuration, and network connectivity.

## Validation Screenshots

* Windows 11 Desktop
* System Information

* Disk Management

* Network Connectivity (ipconfig)

## Results

The virtual machine was successfully deployed and verified. Network connectivity, storage configuration, and operating system functionality were confirmed through testing and documentation.

## Key Takeaways

This lab provided practical experience with virtualization technologies, Windows deployment procedures, system verification, and documentation practices commonly used in IT support environments.
